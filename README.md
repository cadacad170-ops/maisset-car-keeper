# maisset-car-keeper

MVP offline-first de Maisset Company para registrar vehiculos, mantenimientos, kilometraje y servicios realizados.

## Beta fundadora

Acceso directo: https://ko-fi.com/s/bd6d132e3d

La beta se ofrece desde USD 5+ e incluye el paquete actual, acceso anticipado a mejoras y canal directo de feedback.

## Que incluye

- Alta de vehiculos.
- Tareas de mantenimiento con fecha y kilometraje.
- Historial de servicios.
- Persistencia local en el navegador.
- Demo funcional sin dependencias de backend.

## Ejecutar localmente

python -m http.server 8765

Luego abre http://127.0.0.1:8765/.

## Stack

HTML, CSS y JavaScript vanilla. El MVP esta pensado para validar demanda antes de sumar cuentas, recordatorios y sincronizacion.
